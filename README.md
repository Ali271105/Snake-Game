# Snake

A classic Snake game made with Godot 4.

**Play it:** https://ali271105.github.io/Snake-Game/

## Features
- Sprite graphics with a checkerboard grass background
- Title screen, game over screen and a saved high score
- Background music and sound effects (M to mute)
- The snake speeds up as you eat

## Controls
| Key | Action |
| --- | --- |
| Arrow keys / WASD | Move |
| Space / Enter | Start or play again |
| Esc | Back to the title screen (after game over) |
| M | Mute / unmute |

## Run it locally
1. Install [Godot 4.3+](https://godotengine.org).
2. Clone this repo, then in Godot choose **Import** and select `project.godot`.
3. Press **F5**.

## Deploy
Export with **Project → Export → Web** to `docs/index.html`, commit the `docs` folder, and serve it with GitHub Pages (Settings → Pages → `main` branch, `/docs` folder).
